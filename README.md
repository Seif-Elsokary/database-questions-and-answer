# Database Questions & Answers

A collection of SQL problems and database questions solved with detailed explanations and optimized queries.

This repository contains my solutions for database challenges, focusing on improving SQL skills, understanding database concepts, and preparing for Backend Developer interviews.

## What I Do

- Solve SQL problems from platforms like LeetCode.
- Explain the problem requirements and database schema.
- Break down SQL queries step-by-step.
- Explain new SQL concepts introduced in each problem.
- Provide clean and readable SQL solutions.
- Cover different database topics and query techniques.

## Topics Covered

- SELECT & Filtering
- WHERE Conditions
- JOIN Operations
- INNER JOIN / LEFT JOIN / RIGHT JOIN
- GROUP BY & HAVING
- Aggregate Functions
- COUNT, SUM, AVG, MIN, MAX
- UNION & UNION ALL
- Subqueries
- Conditional Logic (IF, CASE WHEN)
- String Functions
- NULL Handling
- Data Transformation
- Database Relationships
- Primary Key & Foreign Key

## Goal

The goal of this repository is to build strong database fundamentals, practice writing efficient SQL queries, and create a useful reference for SQL interview preparation.
